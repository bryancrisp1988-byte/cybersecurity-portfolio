# Summary — Module 2: Computer Hardware

## Purpose
This module teaches the essential physical components that make up a computer system and how they interact.

## Topics Covered
- CPU, RAM, storage devices
- Motherboards, power supplies, expansion cards
- Peripherals and I/O devices
- Hardware troubleshooting basics

## Key Takeaways
- Hardware components work together to support software.
- RAM and storage serve different roles.
- CPUs vary in cores, speed, and architecture.
- Hardware failures often show predictable symptoms.
