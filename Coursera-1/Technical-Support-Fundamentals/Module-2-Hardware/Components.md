# Components — Module 2: Computer Hardware

## What This Lesson Covers
This lesson explores the core physical parts that make up a computer system. It explains how each component contributes to performance and functionality.

## Key Learning Points
- CPU: the brain of the computer, executing instructions.
- RAM: temporary memory for active processes.
- Storage: long-term data retention (HDDs, SSDs).
- Motherboard: connects all components together.
- Power supply: converts electricity for internal use.

## Why It Matters
Understanding components helps IT professionals diagnose hardware issues, upgrade systems, and ensure compatibility between parts.
