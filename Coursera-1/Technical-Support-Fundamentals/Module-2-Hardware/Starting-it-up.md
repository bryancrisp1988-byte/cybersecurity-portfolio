# Starting It Up — Module 2: Computer Hardware

## What This Lesson Covers
This lesson explains what happens when a computer powers on — from BIOS/UEFI initialization to operating system boot.

## Key Learning Points
- POST (Power-On Self-Test) checks hardware integrity.
- BIOS/UEFI loads essential firmware instructions.
- Boot loaders locate and start the operating system.
- Hardware drivers initialize to enable communication.

## Why It Matters
Knowing the startup process helps identify boot failures, firmware issues, and hardware misconfigurations.
