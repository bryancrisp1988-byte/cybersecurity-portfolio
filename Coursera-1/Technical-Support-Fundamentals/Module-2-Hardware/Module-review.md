# Module Review — Module 2: Computer Hardware

## Overview
Module 2 explored the physical components that make up modern computer systems and how they interact to support software and user tasks.

## What I Learned
- Differences between RAM, storage, and cache.
- How CPUs process instructions and why core count matters.
- How motherboards connect all components.
- How peripherals communicate through ports and interfaces.
- Common hardware failure symptoms and troubleshooting steps.

## Skills Gained
- Ability to identify hardware components.
- Understanding of compatibility (RAM type, CPU socket, PSU wattage).
- Basic hardware troubleshooting workflow.
- Knowledge of how hardware impacts performance.

## How This Module Supports Cybersecurity Learning
- Hardware vulnerabilities (firmware attacks, physical access risks).
- Understanding BIOS/UEFI as a security layer.
- Recognising hardware-based attack vectors.

## Personal Reflection
This module strengthened my understanding of how computers physically operate, making future OS and networking modules easier to grasp.
