# Summary — Module 4: Networking

## Purpose
This module explains how devices communicate across networks using hardware, protocols, and addressing systems.

## Topics Covered
- LAN, WAN, and wireless networks
- IP addressing, subnetting, routing
- Common protocols (TCP, UDP, DNS, DHCP)
- Network troubleshooting tools

## Key Takeaways
- Networks rely on protocols to communicate.
- IP addressing determines device identity.
- Routing directs traffic between networks.
- Tools like ping and traceroute diagnose issues.
