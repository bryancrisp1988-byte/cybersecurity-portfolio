# Module Review — Module 1: Introduction to IT

## Overall Summary
Module 1 introduced the foundational concepts of Information Technology. It covered the evolution of computing, the responsibilities of IT support professionals, how computers process information using digital logic, and how modern systems are structured through layered architecture. This module builds the essential baseline for all future IT and cybersecurity learning.

## Key Lessons Covered
### Intro to IT Support
- Role of IT support in organisations
- Importance of communication, documentation, and troubleshooting
- How IT support connects to system reliability and cybersecurity

### History of Computing
- Evolution from mechanical tools to digital computers
- Key innovators (Lovelace, Babbage, Turing)
- Development of personal computers, operating systems, and the internet

### Digital Logic
- Binary representation (0s and 1s)
- Logic gates and truth tables
- How circuits make decisions and form CPU operations

### Computer Architecture Layers
- Hardware → Operating System → Applications → Networking
- How abstraction simplifies complex systems
- Why layered architecture matters for troubleshooting and security

## Skills Gained
- Understanding binary and digital logic  
- Basic hardware and system architecture knowledge  
- Foundational troubleshooting workflow  
- Ability to document technical concepts clearly  
- Awareness of how IT support fits into larger IT and cybersecurity roles  

## How This Module Supports Cybersecurity Learning
- Digital logic explains how vulnerabilities can occur at the hardware level  
- Architecture layers show where attacks target (OS, applications, network)  
- IT support workflows mirror real incident response processes  
- Historical context explains why certain protocols and systems still exist  

## Personal Reflection
This module strengthened my understanding of how computers work at every level — from binary logic to full operating systems. It gave me confidence moving into more advanced topics like networking, system administration, and cybersecurity. I now understand not just *how* computers operate, but *why* they behave the way they do.
