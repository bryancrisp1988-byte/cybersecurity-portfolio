# Introduction to Software — Module 5: Software

## What This Lesson Covers
This lesson introduces what software is, how it differs from hardware, and how it enables computers to perform tasks.

## Key Learning Points
- Software is a set of instructions that tell hardware what to do.
- It includes operating systems, applications, and utilities.
- Software can be proprietary or open‑source.
- Updates and patches improve performance and security.

## Why It Matters
Understanding software fundamentals helps IT professionals manage installations, troubleshoot issues, and maintain system integrity.
