# Interacting with Software — Module 5: Software

## What This Lesson Covers
This lesson explains how users and systems interact with software through interfaces, commands, and automation.

## Key Learning Points
- Graphical user interfaces (GUIs) allow visual interaction.
- Command‑line interfaces (CLIs) provide direct control.
- APIs enable communication between programs.
- Automation tools streamline repetitive tasks.

## Why It Matters
Knowing how software interfaces work helps IT professionals support users, configure systems, and automate workflows efficiently.
