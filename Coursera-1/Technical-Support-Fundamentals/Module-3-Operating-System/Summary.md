# Summary — Module 3: Operating Systems

## Purpose
This module teaches how operating systems manage hardware resources, run applications, and provide user interfaces.

## Topics Covered
- OS architecture and components
- File systems and permissions
- Processes, threads, and memory management
- Windows vs Linux vs macOS basics

## Key Takeaways
- OS manages hardware, software, and user interactions.
- File systems organise data and enforce permissions.
- Processes and memory must be monitored for stability.
- Different OSes have unique tools and structures.
