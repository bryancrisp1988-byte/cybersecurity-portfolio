# What's an Operating System — Module 3: Operating Systems

## What This Lesson Covers
This lesson introduces what an operating system (OS) is and how it acts as the bridge between hardware and software.

## Key Learning Points
- The OS manages hardware resources and software processes.
- It provides a user interface for interaction.
- It handles file systems, memory, and device communication.
- Common OS examples include Windows, Linux, and macOS.

## Why It Matters
Understanding the OS is essential for troubleshooting, system configuration, and ensuring software runs efficiently on hardware.
