# Module Review — Module 3: Operating Systems

## Overview
Module 3 explored how operating systems manage hardware resources, run applications, and provide interfaces for users and administrators.

## What I Learned
- How OS kernels interact with hardware.
- Differences between Windows, Linux, and macOS.
- How file systems store and secure data.
- How processes and memory are managed.
- Basic OS troubleshooting tools (Task Manager, top, ps, logs).

## Skills Gained
- Navigating multiple operating systems.
- Managing files, permissions, and processes.
- Understanding OS architecture and resource allocation.
- Using OS tools for diagnostics.

## How This Module Supports Cybersecurity Learning
- File permissions are critical for security.
- OS logs reveal suspicious activity.
- Process monitoring helps detect malware.

## Personal Reflection
This module helped me understand how systems behave under the hood, making me more confident in troubleshooting and security analysis.
