# Coursera: Technical Support Fundamentals

## Overview
This folder documents my progress through the Coursera Technical Support Fundamentals course, part of the Google IT Support Professional Certificate. It covers IT basics including hardware, operating systems, networking, software, and troubleshooting.

## Skills Gained
- Technical documentation
- Computer hardware fundamentals
- Operating system installation & configuration
- Linux command-line basics
- Networking fundamentals (IP, DNS, routing)
- Software installation & package management
- Troubleshooting methodologies
- Customer support & communication

## Structure
Each module contains:
- A summary of what I learned
- Practical exercises or logs
- Screenshots or diagrams
- Notes and reflections

## Why This Matters
This course builds the foundation for IT support roles and strengthens core skills needed in cybersecurity, networking, and system administration.
