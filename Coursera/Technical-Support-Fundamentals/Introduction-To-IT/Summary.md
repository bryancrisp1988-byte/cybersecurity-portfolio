# Summary — Module 1: Introduction to IT

## Purpose of This Module
Module 1 provides the foundational knowledge needed to understand how computers work, how IT support functions in an organisation, and how modern computing systems evolved. It sets the stage for deeper learning in hardware, operating systems, networking, and cybersecurity.

## Topics Covered

### 1. Intro to IT Support
- What IT support professionals do
- Types of IT support (helpdesk, remote, onsite)
- Importance of communication, documentation, and troubleshooting workflows
- How IT support contributes to system stability and security

### 2. History of Computing
- Early computing devices (abacus, mechanical calculators)
- Key innovators: Ada Lovelace, Charles Babbage, Alan Turing
- Evolution from mainframes to personal computers
- Development of operating systems and graphical interfaces
- Growth of the internet and cloud computing

### 3. Digital Logic
- Binary representation (0s and 1s)
- Logic gates: AND, OR, NOT, XOR
- Truth tables and basic circuit decision-making
- How digital logic forms the basis of CPU operations

### 4. Computer Architecture Layers
- Hardware layer (CPU, RAM, storage)
- Operating system layer (resource management, drivers)
- Application layer (software programs)
- Networking layer (communication protocols)
- How abstraction simplifies complex systems

## Key Takeaways
- Modern computing is built on decades of innovation.
- All digital systems rely on binary and logic gates.
- Computer architecture is layered to simplify complexity and improve reliability.
- IT support is essential for maintaining system functionality and user satisfaction.

## How This Module Fits Into the Course
This module establishes the core concepts required for:
- Understanding hardware (Module 2)
- Navigating operating systems (Module 3)
- Learning networking fundamentals (Module 4)
- Managing software (Module 5)
- Troubleshooting effectively (Module 6)

It is the foundation for all future IT and cybersecurity learning.
