# TryHackMe — Linux Fundamentals Part 1

## Objective
Learn basic Linux navigation commands to interact with file systems.
Demonstrate how you can search for files and introduce shell operators.

## Commands Used
- 'echo'
- 'whoami'
- 'ls'
- 'cd'
- 'cat'
- 'pwd'

## Process
1. output any text that we provide.
2. finds out what user we're currently logged in as.
3. list files in current directory.
4. change directory.
5. concatenate.
6. print working directory.
